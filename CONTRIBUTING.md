# Contributing to Rust Indonesia

Thank you for your interest in contributing to Rust Indonesia!

Rust Indonesia is an independent community initiative that brings together Rust developers, learners, educators, students, and open-source enthusiasts across Indonesia.

We welcome contributions from people with different backgrounds, experience levels, and interests.

## 1. Ways to Contribute

You can contribute to Rust Indonesia in many ways:

- Improve community documentation.
- Help organize meetups, workshops, and events.
- Share Rust learning resources and tutorials.
- Write articles or technical content about Rust.
- Help newcomers learn and use Rust.
- Contribute to community projects and initiatives.
- Report issues and suggest improvements.
- Help manage community communication channels.

You do not need to be an experienced Rust developer to contribute.

## 2. Contributing to This Repository

This repository contains documentation and governance materials for Rust Indonesia.

To contribute:

1. Fork this repository.
2. Create a branch for your changes.
3. Make your changes using clear and consistent Markdown.
4. Review your changes before submitting.
5. Open a Pull Request describing what you changed and why.

For small documentation corrections, you may also open an issue to discuss the proposed change.

## 3. Contribution Guidelines

Please follow these guidelines:

- Keep contributions relevant to Rust Indonesia.
- Write clearly and use respectful language.
- Use English for the primary community governance documentation.
- Keep documentation accurate and easy to understand.
- Prefer simple, accessible Markdown formatting.
- Avoid adding unnecessary dependencies or complexity.
- Provide references when introducing factual claims or external resources.
- Do not publish personal or confidential information without permission.

## 4. Issues and Pull Requests

When opening an issue:

- Use a clear and descriptive title.
- Explain the problem or suggestion.
- Include relevant context and references.

When opening a Pull Request:

- Explain the purpose of your changes.
- Keep changes focused and reasonably small.
- Link related issues when applicable.
- Respond constructively to review feedback.

Contributions may be reviewed by community organizers or designated maintainers before being merged.

## 5. Community Participation

Contributions outside this repository are equally valuable.

If you want to help with community activities, documentation, events, or other initiatives, contact the Rust Indonesia organizers through the community's published communication channels.

Participation is voluntary, and contributors are not required to commit to ongoing responsibilities.

## 6. Community Principles

All contributors are expected to support the principles described in the [Rust Indonesia Community Charter](COMMUNITY_CHARTER.md) and follow applicable community policies.

We encourage:

- Respectful collaboration.
- Open knowledge sharing.
- Constructive discussion.
- Inclusive participation.
- Transparency and accountability.

## 7. Recognition

We value every contribution, regardless of its size.

Contributors may be acknowledged in relevant documentation, project records, or community communications, with their consent where appropriate.

## 8. Questions

If you have questions about contributing, open an issue in this repository or contact the Rust Indonesia organizers through the community's published communication channels.
