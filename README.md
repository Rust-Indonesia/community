# Rust Indonesia

Building connections through Rust.

Rust Indonesia is an independent community initiative that brings together Rust developers, learners, educators, students, and open-source enthusiasts across Indonesia.

Our goal is to build a connected, inclusive, and sustainable Rust community that supports learning, collaboration, open-source contributions, and participation in the global Rust ecosystem.

## Our Mission

- Make Rust more accessible to people across Indonesia.
- Support learning and knowledge sharing at all experience levels.
- Organize meetups, workshops, and community events.
- Encourage open-source contributions and collaboration.
- Connect Indonesian Rust enthusiasts with the global Rust community.

## Get Involved

We welcome anyone interested in Rust, regardless of experience or background.

You can contribute by:

- Sharing knowledge and learning resources.
- Participating in community discussions.
- Organizing or attending meetups and workshops.
- Contributing to open-source projects.
- Helping build the Rust ecosystem in Indonesia.

## Contributing

We welcome contributions from everyone interested in supporting Rust Indonesia.

To contribute to this repository:

- Open an issue to report a problem or suggest an improvement.
- Submit a pull request to propose documentation changes.
- Review existing discussions and contribute constructively.

Please read our [Contributing Guidelines](CONTRIBUTING.md) before submitting changes.

## Independence

Rust Indonesia is an independent local community initiative. It is not an official representative of, or endorsed by, the Rust Project or Rust Foundation unless explicitly confirmed by the relevant organizations.

We respect the [Rust Code of Conduct](https://rust-lang.org/policies/code-of-conduct/) and [Rust Trademark Policy](https://rustfoundation.org/policy/rust-trademark-policy/).
